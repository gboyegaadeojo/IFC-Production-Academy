# Guides for new people

Plain explanations of each part of the app for people joining the production team. The other folders in `docs/` are for the people building and running it.

| Guide                                      | Covers                                                  | Status                       |
| ------------------------------------------ | ------------------------------------------------------- | ---------------------------- |
| [Service Dashboard](service-dashboard.md)  | The live dashboard, the wall TV, and the app name and logo | Being built in stages |

**Keep these current.** Any change to what someone sees or does updates the matching guide in the same pull request (see "Documentation" in `CLAUDE.md`).

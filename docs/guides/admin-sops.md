# Admin: SOP library

**SOP library** holds the procedures for the departments you look after.

## Adding an SOP

1. Choose **Add an SOP**, with a title and department.
2. In the draft, add a summary saying what it's for and when to use it, and the procedure.
3. Upload a file if it has one: a PDF, PNG, or JPEG, up to 10 MB. It's stored privately.
4. **Publish.** The draft becomes the current version.

## Changing an SOP

Choose **Edit SOP**. That starts a draft from the current version, and members keep seeing the current one until you publish. Say what changed. The previous version is kept and marked as replaced, and only the current version can be opened, so nobody follows an old procedure by mistake.

If your department has review before publishing on, someone else with publishing rights has to publish.

## Keeping them current

Under **Settings**, set the owner, category, and how often it needs reviewing. When a review comes up, the owner is reminded.

If you've checked the current version and it's still right, choose to confirm the review. That doesn't need a new version.

## Archiving

**Archive this SOP** when it's no longer in use. Members stop seeing it, and lessons stop listing it. Its versions and files are kept.

## Attaching to lessons

Attach SOPs to a lesson under [Curriculum](admin-curriculum.md). The lesson always shows the current version, so you only update it in one place.
